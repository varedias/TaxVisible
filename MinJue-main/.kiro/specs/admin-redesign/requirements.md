# 管理后台轻量化重新设计 - 需求文档

## 1. 项目概述

### 1.1 背景
当前 MinJue 管理后台功能基础，界面简单。需要重新设计一个轻量化、现代化的管理后台系统，只保留核心功能，快速上线。

### 1.2 目标
- 提供简洁、美观的管理界面
- 实现核心的用户、供应商、商品管理功能
- 快速开发，2-3 周内完成
- 代码简单易维护，不引入过多第三方库

### 1.3 设计原则
- **轻量化优先**：只用必要的库，避免过度设计
- **快速迭代**：先实现核心功能，后续可扩展
- **简单易懂**：代码清晰，新人容易上手

## 2. 核心功能需求

### 2.1 布局系统

#### 2.1.1 侧边栏导航
**用户故事**: 作为管理员，我希望有一个简洁的侧边栏导航，能够快速访问各个功能模块。

**验收标准**:
- [ ] 侧边栏固定宽度 240px
- [ ] 显示 Logo 和系统名称
- [ ] 菜单项显示图标和文字
- [ ] 当前激活菜单高亮显示
- [ ] 菜单项：仪表盘、用户管理、供应商审核、商品管理

#### 2.1.2 顶部导航栏
**用户故事**: 作为管理员，我希望顶部导航栏显示当前页面标题和用户信息。

**验收标准**:
- [ ] 显示当前页面标题
- [ ] 显示用户头像和用户名
- [ ] 显示退出登录按钮

### 2.2 仪表盘

#### 2.2.1 数据统计卡片
**用户故事**: 作为管理员，我希望在仪表盘看到关键业务数据的统计。

**验收标准**:
- [ ] 显示用户总数
- [ ] 显示供应商总数（含待审核数量）
- [ ] 显示商品总数
- [ ] 显示订单总数
- [ ] 每个卡片显示图标和数字

#### 2.2.2 快捷入口
**用户故事**: 作为管理员，我希望在仪表盘快速访问常用功能。

**验收标准**:
- [ ] 显示待审核供应商数量，点击跳转到审核页面
- [ ] 显示最新注册用户（最多 5 条）
- [ ] 显示最新商品（最多 5 条）

### 2.3 用户管理

#### 2.3.1 用户列表
**用户故事**: 作为管理员，我希望能够查看和管理所有用户。

**验收标准**:
- [ ] 显示用户列表（ID、用户名、昵称、角色、状态、注册时间）
- [ ] 支持分页（每页 10 条）
- [ ] 支持搜索（用户名）
- [ ] 支持禁用/启用用户
- [ ] 显示用户角色标签（管理员、供应商、普通用户）
- [ ] 显示用户状态标签（正常、禁用）

### 2.4 供应商审核

#### 2.4.1 待审核列表
**用户故事**: 作为管理员，我希望能够审核供应商申请。

**验收标准**:
- [ ] 显示待审核供应商列表（公司名称、联系人、提交时间）
- [ ] 支持分页（每页 10 条）
- [ ] 点击查看详情，显示完整信息和资质文件
- [ ] 支持审核通过（自动升级用户角色为供应商）
- [ ] 支持审核拒绝（必填拒绝原因）
- [ ] 审核后从列表中移除

### 2.5 商品管理

#### 2.5.1 商品列表
**用户故事**: 作为管理员，我希望查看和管理所有商品。

**验收标准**:
- [ ] 显示商品列表（图片、名称、价格、状态、供应商、创建时间）
- [ ] 支持分页（每页 10 条）
- [ ] 支持搜索（商品名称）
- [ ] 支持筛选（状态：上架/下架）
- [ ] 支持强制下架商品
- [ ] 显示商品状态标签（上架、下架）

## 3. 非功能需求

### 3.1 性能要求
- 页面首次加载时间 < 3 秒
- 列表数据加载时间 < 1 秒

### 3.2 安全要求
- 所有请求需要 Token 认证
- Token 过期自动跳转登录页
- 敏感操作需要二次确认（禁用用户、下架商品、拒绝审核）

### 3.3 兼容性要求
- 支持 Chrome、Firefox、Edge 最新版本
- 最小宽度 1280px（不支持移动端）

### 3.4 可维护性要求
- 组件化开发
- 统一的代码风格
- 简单的注释

## 4. 技术栈（轻量化）

### 4.1 前端技术
- React 19（已有）
- React Router v7（已有）
- Axios（已有）
- Tailwind CSS（已有）
- Lucide React（图标，已有）

### 4.2 不使用的库
- ❌ shadcn/ui（太重，直接用 Tailwind 写组件）
- ❌ React Query（太复杂，直接用 axios + useState）
- ❌ Zustand（太多，用 React Context）
- ❌ Recharts（不需要图表）
- ❌ React Hook Form（简单表单直接用 useState）
- ❌ Zod（简单验证直接写）

## 5. 页面结构

```
/admin
├── /dashboard          # 仪表盘
├── /users              # 用户列表
├── /suppliers/audit    # 供应商审核
└── /products           # 商品列表
```
