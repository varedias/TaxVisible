## 注意事项

1. **任务执行顺序**: 按照周次顺序执行，每周内的任务可以根据依赖关系调整
2. **Checkpoint 任务**: 每个 Checkpoint 都应该暂停并验证当前阶段的工作
3. **需求追溯**: 每个任务都标注了相关的需求和设计章节
4. **代码质量**: 保持代码简单清晰，易于维护
5. **用户体验**: 注重加载状态、错误处理、空状态等细节
6. **轻量化原则**: 不引入新的第三方库，使用现有技术栈
