第一章 系统引言
1.1 编写目的
本《用户操作手册》旨在为“懂视帝工业设备B2B信息服务平台”（以下简称“本系统”）的所有终端用户提供详尽、标准化的操作指导。文档通过对系统功能模块、业务流程及交互逻辑的深度解析，帮助采购方企业快速定位所需设备，协助供应商高效管理产品与订单，并指导系统管理员维护平台的正常运营。本手册是用户掌握系统功能、提升业务处理效率的重要参考资料，同时也是软件交付与验收的核心文档之一。
1.2 项目背景与产品定位
随着工业4.0的推进，传统工业设备的线下采购模式面临着信息不对称、决策周期长、信任成本高等严峻挑战。本系统致力于构建一个垂直领域的综合性B2B服务平台，创新性地融合了“电商交易”与“视频内容社区”双重模式。系统不仅提供包括AI视觉检测、工业机器人等十二大类设备的在线交易与融资租赁服务，更引入了类Bilibili的视频评测机制，通过直观的视觉内容解决远程采购的信任问题，打造“发现-了解-交易-服务”的全周期商业闭环。
1.3 适用对象与阅读指南
本手册适用于以下三类用户：
采购方用户：指有工业设备采购或租赁需求的企业及个人，重点阅读第三章相关内容。
供应商用户：指入驻平台进行产品销售及品牌推广的企业商家，需重点掌握第三章中关于“供应中心”及“商品发布”的操作。
系统管理员：指负责平台运营、审核及系统维护的人员，请重点参阅第四章。
1.4 术语定义
1.  B/S架构：即浏览器/服务器（Browser/Server）架构，用户无需安装专用客户端，通过浏览器即可访问系统核心功能。
2.  JWT：JSON Web Token，用于系统身份验证的加密令牌，保障用户登录安全与权限管控。
3.  RBAC：基于角色的访问控制（Role-Based Access Control），用于后台管理员的权限分级管理。
4.  融资租赁：Financial Leasing，指承租人向出租人支付租金，获得工业设备使用权，租期结束后可选择购买设备的租赁模式。
5.  经营租赁：Operating Leasing，指承租人短期租用工业设备，仅获得使用权，租期结束后归还设备的租赁模式。
第二章 运行环境与配置
2.1 硬件环境要求
本系统采用了轻量化的高性能设计，对客户端硬件资源占用极低。为获得流畅的视频播放体验及高清图片加载速度，建议用户使用具备双核CPU（主频2.0GHz以上）、4GB及以上内存、分辨率不低于1920x1080的计算机设备进行访问。
2.2 软件环境要求
本系统基于B/S（Browser/Server）架构开发，用户端无需安装任何专用客户端软件。系统全面兼容主流操作系统（Windows 10/11、macOS、Linux），建议用户使用Google Chrome、Microsoft Edge或Firefox等现代浏览器访问，以确保CSS3动画效果与React组件的交互功能正常运行。
2.3 系统访问与初始化
用户确保计算机网络连接正常后，启动浏览器，在地址栏输入平台指定的访问地址，按下回车键即可建立连接。系统会自动检测用户的设备类型并适配最佳的响应式布局，首次加载时可能会缓存部分静态资源，后续访问将更加流畅。
第三章 采购方与供应商功能操作指南(前台)
3.1 用户注册与身份鉴权
系统启动后，首次访问且尚未持有平台账号的新用户，为保障交易安全与个性化服务的提供，系统强制要求完成账户注册。用户需点击首页顶部导航栏右侧醒目的“注册”按钮，即可跳转至专用注册页面。
在注册流程中，用户需填写一系列基础身份信息，包括设定唯一的登录用户名、个性化昵称、用于找回密码的电子邮箱地址，并设置高强度的登录密码（需二次确认输入）。为防止恶意脚本攻击与虚假注册，系统集成了严密的双重验证机制：用户首先需正确识别并输入动态生成的图形验证码，随后点击“发送验证码”按钮，前往注册邮箱获取6位数字验证码并回填至系统。只有当图形验证码与邮箱验证码同时校验通过，且勾选同意《用户服务协议》后，注册请求才会被系统后端受理。此外，用户在注册阶段可根据自身业务属性，初步选择“采购方”或“供应商”角色，若选择供应商角色，系统将在注册完成后引导用户进行后续的企业资质认证流程。 
注册成功后，用户通过“登录”入口进入身份鉴权页面。在此页面，用户输入账号与密码，并再次通过图形验证码校验。系统后端基于Spring Security与JWT技术对凭证进行加密比对，验证通过后，系统将自动下发身份令牌，并根据用户的角色属性跳转至相应的业务主页。
  
3.2 平台首页与全局导航
登录系统后，用户将进入平台首页。首页采用了现代化的UI设计语言，顶部为固定悬浮的全局导航栏，通过清晰的菜单指引用户快速抵达“商城”、“发现”、“租赁”、“供应商”等核心业务模块。首页主体区域包含Banner轮播图，用于展示平台最新的促销活动或热门设备推荐；下方则通过智能推荐算法，分区块展示了“热门商品”、“精选视频评测”及“优质供应商”推荐，帮助用户快速获取行业前沿动态。
 
 

 

3.3 工业商城与智能选型系统
点击导航栏的“商城”按钮，即进入工业设备选购大厅。该模块左侧设置了多级分类导航树，涵盖了AI视觉检测、工业相机、光源镜头、工业机器人等12大类工业垂直品类。为解决工业品参数复杂、选型困难的痛点，系统顶部集成了强大的智能筛选引擎，用户可以根据品牌归属、价格区间、库存状态及上架时间等多维度条件进行组合过滤。同时，商城列表支持“网格视图”与“列表视图”的一键切换，满足用户偏重图片浏览或偏重参数对比的差异化习惯。点击任意商品卡片，进入详情页，用户可查看高清产品图集、详细规格参数表、实时库存数量以及其他用户的评价信息。
 
 
3.4 视频内容发现社区
“发现”模块是本平台区别于传统B2B网站的核心特色。点击进入后，用户将看到一个类Bilibili模式的视频内容社区，页面采用瀑布流布局展示海量的设备开箱视频、操作教程及行业专家评测。用户点击视频封面即可进入沉浸式播放页面，系统支持高清视频流的流畅播放。在交互层面，用户不仅可以观看视频，还可以对优质内容进行点赞、收藏，或在下方的评论区发表专业见解，与供应商及其他工程师进行技术交流，这种“内容+社交”的模式极大地降低了远程采购的信任成本。
 
 
3.5 工业设备租赁服务
针对高价值工业设备一次性投入大的痛点，平台开辟了专业的“租赁”服务板块。进入该模块，系统清晰地划分了“融资租赁”（Financial Leasing）和“经营租赁”（Operating Leasing）两种业务模式，用户可根据企业的资金流转情况灵活选择。在租赁详情页，系统详细列出了设备的日租金、周租金及月租金费率方案。用户选定租赁周期后，系统会自动计算预估总费用，用户点击“申请租赁”并填写企业资质及联系人信息，即可一键提交租赁意向单，后台将自动流转至相关部门进行审核与对接。

3.6 供应商黄页与即时通讯
平台构建了详尽的供应商黄页数据库。用户点击“供应商”导航，可浏览所有经过平台认证的入驻企业名录。点击特定企业名称，进入“企业主页”，该页面全方位展示了企业的工商注册信息、ISO质量体系认证、经营年限以及该企业发布的所有在售产品线，帮助采购方建立商业互信。为了提高沟通效率，页面右下角集成了即时通讯（IM）组件，用户点击“在线咨询”按钮即可唤起聊天窗口，直接与供应商业务人员进行一对一的即时沟通，支持发送文字、表情及图片，方便进行询价和技术确认

3.7AI智能搜索与设备匹配 
用户在浏览平台的过程中，可随时通过“AI智能搜索”功能快速定位适合自己的设备。用户只需输入关键需求（如应用场景、预算范围、精度要求、品牌偏好等），或选择结构化条件，系统内置的AI模型会自动理解需求要点，对平台商品库与供应商能力进行综合分析与匹配。在搜索结果页，用户可以查看AI推荐的设备清单，支持按价格、销量、评分等多维度排序与筛选，并可对单个设备展开参数对比与详情查看。对于有进一步个性化需求的用户，系统还支持基于对话式交互的智能问答与二次推荐，引导用户逐步澄清需求、缩小选择范围，最终锁定最优设备方案，提高选型效率与决策质量。
 
 
3.8 个人中心与供应中心
登录状态下点击头像进入个人中心。
采购方视图：主要包含“我的订单”（查看订单状态、物流信息）、“我的收藏”（管理收藏的商品与视频）、“账号设置”（修改密码及个人资料）。
 
 

供应商视图（供应中心）：认证通过的供应商拥有独立的工作台。工作台直观展示了今日访客数、待处理订单及累计销售额等核心经营数据。供应商可在此模块进行“发布商品”操作，录入商品名称、分类、价格、库存及详情描述；亦可对已上架商品进行编辑、下架或删除管理。
 
 

第四章 系统管理与运营操作指南（后台）
4.1运营数据仪表盘
管理员登录成功后，默认进入运营数据仪表盘（Dashboard）。该页面通过可视化的数据图表，实时呈现平台的核心运营指标，包括注册用户总数、入驻供应商总数、在售商品总量以及今日订单交易额趋势图。右侧动态栏会实时推送最新注册的用户列表及待审核事项，帮助管理员一目了然地掌握平台整体运行健康度，辅助运营决策。
 
4.2 供应商入驻资质审核
平台实行严格的供应商准入机制，该环节由管理员在“供应商管理”模块完成。管理员需定期查看状态为“待审核”的入驻申请记录。点击“详情”按钮，系统预计将展示申请企业提交的营业执照高清图片、统一社会信用代码及企业简介等资料。管理员需人工核验资料的真实性与合规性。审核通过，点击“通过”按钮，系统自动赋予该账号供应商权限；若审核不通过，点击“驳回”并填写具体修改意见，系统将通知用户重新提交。
 
 
4.3 商品监管与内容治理
管理员拥有对平台所有公开内容的最高监管权。在“商品管理”模块，管理员可检索全平台商品，对于价格异常、涉嫌虚假宣传或违禁的商品，可直接执行强制下架或删除操作，确保商城环境合规。在“交互管理”模块，管理员可以监控发现社区内的视频评论与帖子，对于用户举报或系统关键词过滤出的违规言论，管理员可进行删除或屏蔽处理，切实维护社区良好的交流氛围。

4.4 用户权限与交易管理
在“用户管理”模块，管理员可以查看全平台注册用户的详细档案，支持按手机号或用户名进行精准检索。对于违反平台规定的恶意账号，管理员可执行“封禁”操作，限制其登录权限；待违规行为消除后，可进行“解封”恢复。同时，管理员可在“订单管理”模块查询所有交易记录，对于长时间未发货或存在交易纠纷的异常订单，管理员具备介入处理、修改状态或强制关闭订单的权限，以保障买卖双方的合法权益。
