export const procurementApi = {
    getList(params)      // 获取采购列表 (分页、关键词、状态)

### 1.6 交互功能 API (新建模块)
**文件位置**：`frontend/src/api/interaction.js`（全新文件）

包含 4 个子 API：

#### (1) 评论 API (`commentApi`)
```javascript
export const commentApi = {
    getList({ productId, page, size })  // 获取商品评论
    getCount(productId)                   // 获取评论数
    add({ productId, rating, content })  // 发表评论
    delete(id)                            // 删除评论
    helpful(id)                           // 标记评论有用
}
```

**对接后端**：`GET /api/v1/interaction/comment/list`、`POST /api/v1/interaction/comment`、`DELETE /api/v1/interaction/comment/{id}`

**使用页面**：
- ProductDetail.jsx (评价 Tab)

#### (2) 点赞 API (`likeApi`)
```javascript
export const likeApi = {
    toggle({ targetId, targetType })     // 切换点赞
    check({ targetId, targetType })      // 检查是否已点赞
    count({ targetId, targetType })      // 获取点赞数
}
```

**对接后端**：`POST /api/v1/interaction/like/toggle`、`GET /api/v1/interaction/like/check`

**使用页面**：
- Discovery.jsx (内容卡片点赞)
- ContentDetail.jsx (内容详情点赞)

#### (3) 收藏 API (`favoriteApi`)
```javascript
export const favoriteApi = {
    toggle({ targetId, targetType })     // 切换收藏
    check({ targetId, targetType })      // 检查是否已收藏
    list({ page, size, targetType })     // 获取收藏列表
}
```

**对接后端**：`POST /api/v1/interaction/favorite/toggle`、`GET /api/v1/interaction/favorite/list`

**使用页面**：
- ProductDetail.jsx (商品收藏)
- Discovery.jsx (内容收藏)
- PersonalCenter.jsx (我的收藏 Tab)

#### (4) 分享 API (`shareApi`)
```javascript
export const shareApi = {
    add({ targetId, targetType, platform })  // 记录分享
    count({ targetId, targetType })          // 获取分享数
}
```

**对接后端**：`POST /api/v1/interaction/share`、`GET /api/v1/interaction/share/count`

**使用页面**：
- ContentDetail.jsx (内容分享)
